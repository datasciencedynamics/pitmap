Interpolators

Interpolators that share one fit/predict interface.

Each class takes survey points as an (n, 2) array of x, y coordinates and an (n,) array of elevations (or any indicator such as ore grade) z, and predicts z at new x, y locations.

Methods follow the automated geological and mine-surveying support system described in Zelenskyi et al. (2020), Zelensky & Lysenko (2023), and Zelensky & Donchenko (2025).

class pitmap.core.interpolation.NearestRegion[source]

Bases: object

Polygonal (nearest-region / Thiessen polygon) surface.

Every location takes the elevation of its closest survey point, so the surface is piecewise constant over the Voronoi cell of each point. This is the classical polygonal method of mine surveying and reserve estimation (Zelensky & Lysenko, 2023, section 4).

class pitmap.core.interpolation.SectorIDW(radius, power=2.0, n_sectors=8, anisotropy=None)[source]

Bases: object

Sector-constrained inverse distance weighting.

The value at a query point is a weighted average of nearby survey points, with weight 1 / d**power (Zelenskyi et al., 2020; Zelensky & Donchenko, 2025, eq. 11). To stop a cluster of points on one side from dominating, the search circle of the given radius is cut into n_sectors equal angular sectors and only the single closest point in each sector is used (2020 paper, Fig. 3). Query points with no survey point inside the radius return NaN.

Parameters:

  • radius (float) – Search radius in the units of xy.

  • power (float, default 2.0) – Distance exponent alpha. 2 is the usual choice.

  • n_sectors (int, default 8) – Number of angular sectors around each query point.

  • anisotropy (tuple[float, float] or None) – Critical correlation radius along x and along y, (rk_x, rk_y). When given, distances are scaled by rk_max / rk_axis before weighting so a point along the better-correlated axis counts as closer (Zelensky & Donchenko, 2025, eq. 12-13). None means isotropic.

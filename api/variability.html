Spatial variability

Spatial variability of a sequence of control points.

Autocorrelation function (ACF) and the critical correlation radius, as used in the automated geological and mine-surveying support system (Zelensky & Lysenko, 2023; Zelensky & Donchenko, 2025, eq. 10).

pitmap.core.variability.autocorrelation(values, max_lag=None)[source]

Autocorrelation coefficients r_m for lags m = 0 .. max_lag.

r_m is the Pearson correlation between the first n - m values and the sequence shifted by m. max_lag defaults to n // 4, the usual recommendation. values must be in sequence order (for example along a borehole or a survey line).

Parameters:

max_lag (int | None)

Return type:

ndarray

pitmap.core.variability.lag1_autocorrelation(values)[source]

r_1, the autocorrelation between adjacent control points.

Zelensky & Donchenko (2025) treat r_1 > 0.7 as a consistent spatial trend worth modelling and r_1 <= 0.7 as a set of effectively random values.

Return type:

float

pitmap.core.variability.critical_radius(values, step=1.0, max_lag=None)[source]

Critical correlation radius r_k.

Distance at which the ACF first crosses zero, found by linear interpolation between the last positive and first non-positive coefficient, multiplied by step (the spacing between control points). Returns inf if the ACF stays positive over all computed lags.

Parameters:

  • step (float)

  • max_lag (int | None)

Return type:

float

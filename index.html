Welcome to the pitmap documentation

Note

This documentation is for pitmap version 0.0.0a5 (pre-alpha). The API will change.

pitmap builds surfaces from scattered survey points for open-pit mine surveying. It is a Python implementation of the surface-construction methods used in the automated geological and mine-surveying support system developed at the State University of Economics and Technology (Kryvyi Rih, Ukraine), with a kernel-based interpolator added for comparison. Every interpolator shares one fit / predict interface.
